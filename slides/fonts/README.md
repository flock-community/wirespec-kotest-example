# Fonts

Self-hosted so the slides also work offline. All three families are licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org) and were downloaded from Google Fonts
(Latin subset, variable weights):

- [Funnel Display](https://fonts.google.com/specimen/Funnel+Display): headings
- [DM Sans](https://fonts.google.com/specimen/DM+Sans): body text
- [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono): code
